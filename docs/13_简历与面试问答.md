## 3. 面试问答库（按模块，附答题要点）

### 3.1 项目总览类

**Q：介绍一下这个项目。**（90 秒版）
要点：定位（200 元学习平台）→ 架构（ESP32-S3 固件 + micro-ROS + ROS2 三层）→ 你做了什么（工程基线/环境/固件移植/阶段推进）→ 量化结果（0 error、镜像大小、各话题频率）→ 你的角色（个人项目全流程）。

**Q：为什么选这个项目？**
要点：成本门槛（对比数千元套件）→ 覆盖面（硬件到算法全链路）→ 开源可复现 → 与求职岗位的匹配点。

**Q：项目中最大的难点？怎么解决的？**
要点（P2 实例，有完整证据链）：表面是 PermissionError，实际是 lock 文件写死上游绝对路径 + v5→v6.1 六处破坏性变更 + 预编译库依赖链失效三层叠加。讲你的方法论：读 traceback → grep 定位写入者 → 区分根因类型 → 每轮修复后全量编译验证 → 沉淀幂等脚本。

**Q：你一个人做的？别人（上游）提供了什么？**
要点：硬件与软件来自开源方案（说明你选择了什么、改了什么）；强调个人增量：工程基线、版本兼容性判定与迁移、文档体系、阶段复盘。**不要贪功，也不要妄自菲薄。**

### 3.2 架构与通信类

**Q：为什么 MCU 用 micro-ROS 而不是直接跑 ROS2？**
要点：ESP32-S3 资源（RAM/Flash）跑不动完整 DDS 栈；micro-ROS 把 XRCE-DDS 客户端编译进固件，Agent 在 PC 侧代理 DDS 通信；代价是依赖 Agent 进程。

**Q：micro-ROS 的传输你们用了哪种？为什么？**
要点：默认 Wi-Fi 自定义 UDP（免接线， agent `192.168.31.214:8888`）；保留 UART 传输（921600，GPIO43/44）应对无路由器/禁无线场景；传输层可切换，配置存 NVS。

**Q：Wi-Fi UDP 做控制怕不怕丢包？**
要点：50 Hz 高频发布天然容错（丢一帧下一帧补）；`/cmd_vel` 带超时与急停逻辑（固件 `g_emergency_stop`）；关键指令有 ACK 语义的服务（PID 服务）；实验室场景切换 UART 传输。

**Q：`/cmd_vel` 到电机转速中间发生了什么？**
要点：`/cmd_vel`(Twist, m/s) → microros_task 入队 → motion_task(20ms) → motion_controller 差速运动学分解左右轮速 → 速度环 PID → PWM；编码器 PCNT 反馈闭环。

### 3.3 固件与嵌入式类

**Q：固件架构怎么组织的？**
要点：`app_main → app_runtime`；FreeRTOS 多任务（motion/imu/lidar/ultrasonic/battery/peripheral/gamepad）经队列解耦；13 个 components 按驱动分层；NVS 存运行配置。

**Q：编码器怎么读的？里程计怎么算的？**
要点：PCNT 外设计脉冲（不占 CPU）；单位时间脉冲差 → 转速 → 结合轮距 131.7 mm 积分位姿；50 Hz 发布 `nav_msgs/Odometry`。

**Q：PID 在哪几层？怎么整定？**
要点：速度环 + 位置环双环；通过 ROS 服务 `/set_speed_pid` 在线改参数写 NVS；整定方法：阶跃响应看超调/静差/抗扰，先 kp 后 ki 再 kd 微调。

**Q：I²C 手柄断连了车会怎样？**
要点：20 Hz 轮询 `0x50`；死区 12 的摇杆映射（左 Y→线速度 300mm/s，右 X→角速度 2.5rad/s）；断连只释放手动接管、不发零速，继续执行最近导航指令——这是文档明确的语义。

### 3.4 ROS2 类

**Q：为什么 bringup 要把 `/odom` 转成 TF？**
要点：ROS2 生态（RViz/Nav2/SLAM）以 TF 树为坐标基准；`odom→base_footprint` 由里程计填充，`map→odom` 由 SLAM/AMCL 填充，两者拼出完整定位链。

**Q：QoS 怎么选的？**
要点：传感器数据流用 sensor-data QoS（best-effort，适配高频丢包容忍）；服务用 reliable；micro-ROS 侧需与 agent/订阅端匹配。

**Q：自定义接口有哪些？**
要点：`leap_interfaces` 的 `SetSpeedPid/GetSpeedPid` 服务；雷达数据用标准 `LaserScan`，优先复用标准消息而非自定义。

**Q：colcon 工作空间怎么组织？多包依赖怎么处理？**
要点：`src/` 放包 → `colcon build --symlink-install` → `source install/setup.bash` overlay；`--packages-select` 单包构建加速迭代；rosdep 装系统依赖。

### 3.5 SLAM / Nav2 类（完成阶段 4/6 前只答原理，完成后再讲实操）

**Q：gmapping 和 Cartographer 区别？**
要点：gmapping 是 Rao-Blackwellized 粒子滤波（轻量、2D、易上手）；Cartographer 是图优化 + 子图（精度高、支持 3D/多传感器、参数复杂）。实践选型看地图质量/CPU/与 Nav2 衔接。

**Q：建图时点云扭曲怎么解决？**
要点：降遥控速度；用 IMU/里程计做运动补偿；提高雷达有效频率；Cartographer 配置运动畸变过滤。

**Q：Nav2 从给定目标到到达，内部发生了什么？**
要点：BT Navigator 行为树 → 全局规划（A*/Smac 在 static map）→ 局部规划（DWB 在 local costmap）→ 控制器发 `/cmd_vel` → 失败时恢复行为（rotate/clear_costmap/backup）→ AMCL 用 `/scan` 修正 `map→odom`。

**Q：costmap 有哪几层？膨胀半径为什么这样设？**
要点：static（地图）/ obstacle（雷达）/ inflation（障碍代价衰减）/ voxel（3D）；膨胀半径 ≥ 机器人 footprint 半径 + 安全裕量，过大窄通道过不去、过小会贴障。

### 3.6 工程素养类

**Q：大版本升级（v5→v6.x）你的兼容性判定与迁移方法？**
要点：先实编译实验取证（配置/编译分层收集错误）→ 列破坏性清单 → 评估「修复 vs 迁移」成本（本项目 6 类变更修复成本高于换 v5.5.3，决策迁移）→ 迁移后全量验证 → 排障证据沉淀文档。

**Q：怎么保证别人能复现你的环境？**
要点：一键脚本 + 版本 pin（submodule commit、IDF 版本、lock 文件）+ 环境快照归档（docs/env-backup）+ 每阶段文档带实测数据。

**Q：和上游开源社区怎么协作？**
要点：fork → 个人 patch（上游构建残留清理等）→ 提 ISSUE/PR；遵守 license（禁商用，个人学习保留边界）。
